# Tipometer

A single-screen tip calculator, installable as a mobile PWA. Tap `−` / `+` to
move the tip rate in 0.5% steps (starting at 15%), type the bill total, and read
the tip and the grand total underneath.

- **Big, glanceable rate** — the percentage is the largest thing on screen.
- **0.5% steps** — tap for one step, press and hold to run through the range.
- **Bill total field** — numeric keypad on mobile; accepts `.` or `,` as the
  decimal mark.
- **Offline and installable** — service worker caches the app shell; "Add to
  Home Screen" launches it standalone.
- **Remembers your last rate and bill** via `localStorage`.
- **Currency** follows the browser locale (falls back to USD).

## Running it

Any static file server works — a service worker needs `http(s)`, not `file://`:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

Deploying is a matter of copying the directory to any static host (GitHub Pages,
Netlify, S3). All paths are relative, so it works from a subdirectory.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The one screen |
| `styles.css` | Dark theme, safe-area aware layout |
| `app.js` | Tip state, rounding, press-and-hold, persistence |
| `sw.js` | Offline cache (bump `CACHE` to ship an update) |
| `manifest.webmanifest` | Install metadata |
| `icons/` | App icons, generated by `tools/make-icons.py` |
